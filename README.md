# Mastherthesis-Script-and-Extreme-Event-Catalogue
The script provides an analysis for long-term oxygen trends, an empirical approach of extreme event definition after Hobday, the corresponding analysis looking at frequency, duration and intensity of events, and finally a correlation of driver candidates and dominance to extreme events. Results can be collected within one excel file. 
The mean daily oxygen data as well as driver candidates data used has been provided by the open sources FGG Elbe, WSV and HPA. The initial script is constructed for .csv files. Correlation analysis has been writen for water temperature, conductivity, chlorophyll, ph and turbidity. Changes within stations need to be adapted accordingly to file type and available data. It is recommended to analyse each station in a separated script to exclude overwritting errors (this was the approach applied in the thesis). Still, only the script for one station is provided here (Bunthaus). The catalogue with all computed results is uploaded here.
